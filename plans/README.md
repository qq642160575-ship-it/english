## 核心原则

1. **每个功能独立可上线**：互不依赖
2. **最小实现**：每个方案都给出了"最简单可上线版本"，不使用额外库，不引入后端
3. **纯前端**：所有数据持久化使用 localStorage，API 全部是浏览器原生
4. **不改现有数据格式**：新功能不破坏已有进度存储
